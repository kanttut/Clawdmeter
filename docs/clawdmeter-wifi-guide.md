# Clawdmeter — инструкция по экрану и пульту Windows

Для **Waveshare ESP32-C6-Touch-AMOLED-2.16** с сенсорным экраном 480 × 480 и нашей прошивкой с ретро-Clawd. Для ветки `clawdmeter-wifi-codex`.

## Первичная установка

1. Установи Python 3.11 или новее и PlatformIO CLI на Windows. Открой PowerShell в корне клонированного репозитория.
2. Для первой установки подключи плату USB-кабелем с передачей данных, узнай её COM-порт и подставь его вместо `COM9`.

   ```powershell
   pio run -d firmware -e waveshare_amoled_216_c6 -t upload --upload-port COM9
   ```

3. Установи зависимости и зарегистрируй службу в автозагрузке текущего пользователя Windows.

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install-windows.ps1
   ```

4. Настрой Wi‑Fi через USB по [инструкции ниже](#wifi-setup). Открой пульт из корня репозитория командой `& '.\.venv\Scripts\pythonw.exe' '.\daemon\panel_windows.py'`. На этом этапе можно создать ярлык для этой команды на рабочем столе.
5. Войди в Claude Code и Codex на компьютере. Для локальных заметок и пульта эти аккаунты не нужны.

## Быстрый старт

1. Разбуди экран касанием. Компьютер должен быть включён, а экран и ПК должны быть в одной домашней сети. Экран подключается к Wi‑Fi **2,4 ГГц**. ПК может быть подключён к тому же роутеру кабелем.
2. Открой **«Пульт Clawdmeter»** командой выше или через созданный ярлык.
3. Дождись статуса **«На связи»** в пульте. Под ним показано, как давно экран получил данные Claude и Codex. На первом запуске или после пробуждения дай фоновой службе завершить очередной цикл.
4. Правой кнопкой выбери **Claude → Codex → Заметки**. Для проверки передачи напиши в пульте одну строку, нажми **«Отправить список»**, поставь галочку на экране и проверь, что в пульте увеличилось число выполненных дел.

## Кнопки, касания и режимы

| Действие | Результат |
| --- | --- |
| Правая кнопка **KEY**, короткое нажатие | Следующая страница по кругу. Выходит из заставки или игры и переключает страницу, даже если сработала пауза после касания или страница закреплена. |
| Левая кнопка **BOOT**, короткое нажатие | Открывает или закрывает анимированную заставку. |
| Левая кнопка, пять коротких нажатий подряд | Запускает игру с Clawd. Между нажатиями оставляй меньше секунды. |
| Левая кнопка, удержание от 3 до 5 секунд | При отпускании запускает глубокий сон. Дисплей гаснет, сетевой обмен прекращается. |
| Левая кнопка, удержание 5 секунд | Включает или выключает тестовый режим. |
| Средняя кнопка **PWR**, короткое нажатие | Переключает яркость по кругу, от 25 до 100%. |
| Короткое касание рабочей страницы | Откладывает автоматическое перелистывание на 15 секунд. |
| Удержание пальца около 0,7 секунды | Закрепляет рабочую страницу. Снять закрепление можно через пульт или переключить страницу правой кнопкой. |
| Касание иконки батареи | Показывает процент заряда примерно на 5 секунд. |
| Касание погасшего экрана | Пробуждает плату через прерывание тачскрина. Если отклика нет, включи плату кнопкой питания и дождись возврата в сеть. |

**Автоперелистывание.** Стандартный интервал — **5 секунд**. В пульте открой **«Управление» → «Смена, сек.»**, введи число от **3 до 60** и нажми **«Применить»**. Автосмена относится к Claude, Codex и заметкам. В заставку и игру можно перейти отдельно.

**Заставка.** Запускается левой кнопкой или из пульта. В текущей сборке 18 анимаций с выбранным ретро-дизайном Clawd. Заставка входит в экранное время, пока дисплей горит. Посмотреть набор можно в [превью 18 анимаций](../assets/clawdmeter-retro-preview.gif).

**Ожидание данных.** Общая сцена для Claude и Codex с надписью **«ждем информации с компа»** включается, пока у открытой страницы ещё нет данных. Clawd и логотип ChatGPT перекидывают мяч с разной скоростью, паузами и траекториями. Если страница уже получила данные и они устарели, прошивка оставляет последние значения, приглушает их и показывает возраст.

**Игра.** После пяти коротких нажатий левой кнопки или по кнопке **«Игра»** в пульте Clawd подаёт мяч. Дождись надписи **«Бей!»** и коснись экрана, когда мяч справа. У подач разные траектории и темп. Удачные удары подряд повышают комбо. Для выхода нажми правую кнопку или выбери страницу в пульте.

**Глубокий сон.** На этой модели он запускается и от батареи, и на USB. Достаточно любого из двух условий — **10 минут без касаний и нажатий** или **10 минут без изменения полученных процентов использования**. Новый пакет с теми же процентами сам по себе второй таймер не сбрасывает. В глубоком сне дисплей выключен, Wi‑Fi недоступен и плата не отвечает на команды, заметки или OTA. После касания плата запускает прошивку заново и подключается к сети. Заметки, галочки и сохранённое экранное время остаются во внутренней памяти.

## Тестовый режим

Удерживай левую кнопку 5 секунд до появления подписи `Demo 1/4`. Правая кнопка перебирает сценарии, короткое нажатие левой меняет Claude и Codex в том же сценарии. Для выхода снова удерживай левую кнопку 5 секунд.

| Сценарий | Остаток за 5 часов | Остаток за неделю |
| --- | --- | --- |
| 1 · Мало | 10% | 10% |
| 2 · Половина | 50% | 50% |
| 3 · Почти полный лимит | 90% | 90% |
| 4 · Пятичасовой лимит исчерпан | 0%, таймер и анимация | 25% |

Полоски показывают **использованный** процент, поэтому при остатке 90% на полоске написано 10%. В каждом сценарии время сброса рассчитано от условных 12:00. Данные от ПК продолжают поступать в фоне. Автоперелистывание приостанавливается, а через 10 минут без действий экран может уснуть.

## Лимиты Claude и Codex

### Что показывает устройство

| Страница | Данные и оформление |
| --- | --- |
| **Claude** | Пятичасовое окно **Current** и недельное окно. Проценты показывают использованную долю каждого лимита. |
| **Codex** | Пятичасовое окно **5-hour** и недельное окно Codex, логотип ChatGPT и белая строка `Thinking...` / `Thinking..` / `Thinking.` при обычном показе. |
| **Обе страницы** | Справа от `Resets in …` отображается местное время сброса, если его вернул источник. При исчерпании пятичасового лимита его полоску заменяет таймер `ЧЧ:ММ:СС` и появляется анимация с мячом у стены. |

Таймер исчерпанного лимита идёт на устройстве с шагом в секунду. При достижении нуля новый процент появится после очередного успешного получения данных с ПК. Если источник не прислал время сброса, экран показывает `Reset time pending`. Когда точное время выглядит неверным, проверь часы и часовой пояс Windows.

### Откуда берутся данные и как часто они обновляются

1. **Claude.** Фоновая служба Windows берёт локальный вход Claude Code и запрашивает сведения об использовании у Anthropic. Если вход истёк, заново войди в Claude Code под тем же пользователем Windows.
2. **Codex.** Служба запускает `codex.exe app-server` из `PATH` или из установленного приложения Codex для Windows и вызывает `account/rateLimits/read`. Используется авторизованный аккаунт Codex на ПК. Служба ожидает окна длительностью 5 часов и 7 дней. Если вход не подтверждён или источник не возвращает оба окна, данные Codex не обновятся.
3. **Передача.** ПК отправляет экрану проценты, сведения о сбросе и местное время. Данные каждого сервиса обновляются независимо. Токены аккаунтов остаются на ПК.
4. **Частота.** Служба ждёт **60 секунд после окончания цикла** перед следующим запросом. Фактический интервал также включает время запросов и доставки. Открытый пульт опрашивает состояние платы примерно **каждые 4 секунды**. Этот опрос показывает, когда пришли лимиты, и сам их у сервисов не запрашивает.

Если проценты стоят на месте, сначала посмотри на отметки **Claude** и **Codex** под статусом в пульте. Если там регулярно появляется **«только что»**, данные доходят. Процент может оставаться прежним. Если возраст растёт и после примерно 90 секунд значения на экране побледнели, проверь службу и вход в соответствующий сервис.

### Запуск фоновой службы

Для фонового обновления в области уведомлений Windows должен работать **Clawdmeter**. В меню его значка есть **Start at login** для запуска при входе в Windows и **Quit** для завершения работы службы. Пульт можно закрыть, пока значок фоновой службы остаётся в трее.

Если значка нет, открой PowerShell в корне репозитория, и запусти службу в установленном окружении.

```powershell
.\.venv\Scripts\python.exe -m daemon.tray_windows
```

## Заметки и передача данных с экрана на ПК

### Отправить, отметить или удалить заметку

1. Открой пульт и в разделе **«Заметки»** впиши **одно дело на строку**. Пустые строки пропускаются. Можно отправить до 12 дел, пока весь пакет занимает не больше 512 байт. Кириллица и длинные строки быстрее заполняют этот объём, поэтому при сообщении **«Список слишком длинный»** сократи формулировки.
2. Нажми **«Отправить список»** или **Ctrl+Enter** и дождись **«Список отправлен»**.
3. Выбери **«Заметки»** на устройстве. При необходимости прокрути список по вертикали. Текст крупный, слева у каждого дела есть квадрат.
4. Коснись квадрата. Появится зелёная галочка, строка зачеркнётся и переместится вниз. Повторное касание снимает отметку. Пульт на следующем опросе покажет, сколько дел выполнено и какие именно.
5. Для удаления одной заметки убери её строку на ПК и снова отправь список. Для очистки всех заметок отправь пустое поле. **После отправки изменённого списка сбрасываются все галочки.** Если повторно отправить точно тот же текст, отметки сохранятся.

Приложение хранит копию последнего отправленного из него списка в `%LOCALAPPDATA%\Clawdmeter\note.txt`. Плата хранит свой список и галочки во внутренней памяти. Обратно по Wi‑Fi приходят отметки выполнения, а пульт сопоставляет их с локальной копией строк. Если отправить заметку другим скриптом, пульт сам её текст не подгрузит.

### Что ещё можно узнать с экрана

| Показатель | Где смотреть |
| --- | --- |
| Доступность, открытая страница или режим, закрепление, яркость и интервал перелистывания | **«Управление»** и строка состояния пульта. |
| Как давно пришли лимиты Claude и Codex | Строка под статусом в пульте. Сами проценты видны на страницах экранчика. |
| Сколько времени горел дисплей | **«Экранное время» → «Сегодня»**, **«Последние 7 дней»**, **«Всё время с установки счётчика»**. Учитываются рабочие страницы, игра и заставка. При выключенном дисплее счётчик стоит. |
| Время после последнего отключения внешнего питания | **«Экранное время» → «С последней зарядки»**. Отсчёт начинается с зафиксированного отключения кабеля, независимо от того, успела ли батарея зарядиться до 100%. При подключённом питании пульт показывает **«На внешнем питании»**, до первого известного отключения — **«Жду отключения зарядки»**. |
| Текущий процент заряда | Касание батареи на устройстве. Текущий пульт этот процент не запрашивает. |

Дни в статистике определяются по местному времени, которое плата получает с ПК. Пока плата спит, цифры в пульте могут оставаться на последнем полученном значении. Для актуального состояния разбуди её и дождись ответа.

## Подключения и настройка Wi‑Fi

| Канал | Для чего используется |
| --- | --- |
| **Wi‑Fi в домашней сети** | Лимиты, заметки, галочки, команды пульта, экранное время и обновление прошивки OTA. Для лимитов ПК также нужен интернет. Уже настроенные пульт и заметки работают локально. |
| **USB с передачей данных** | Первая настройка Wi‑Fi, смена сети или восстановление связи, диагностика через COM-порт и проводная перепрошивка при необходимости. Обычную синхронизацию лимитов по USB эта сборка не реализует. |
| **Bluetooth LE** | Старый режим синхронизации, пока на устройстве не настроен Wi‑Fi. Рабочий режим текущего пульта и OTA — Wi‑Fi. |

При смене роутера или пароля подключи **одну** плату кабелем с передачей данных. Разбуди экран, закрой программы, которые держат его COM-порт, и запусти в PowerShell из папки проекта.

```powershell
& '.\.venv\Scripts\python.exe' `
  '.\daemon\setup_wifi_windows.py'
```

В окне **«Clawdmeter · Настройка Wi‑Fi»** введи точное имя сети 2,4 ГГц и пароль. Нажми **«Подключить»**. Не отключай кабель, пока программа не подтвердит связь. Она записывает параметры на плату по USB, ждёт подключения к роутеру, проверяет ответ по сети и сохраняет параметры ПК в `%LOCALAPPDATA%\Clawdmeter\wifi.json`. Этот файл содержит ключ сопряжения. Его содержимое не нужно отправлять в чат или прикладывать к журналу.

Если настройка не проходит, проверь кабель, имя и пароль сети, наличие COM-порта и доступность платы с ПК. Гостевая сеть или изоляция клиентов могут не дать устройствам связаться, даже когда оба подключены к одному роутеру. Если была запущена старая BLE-служба, после успешной настройки перезапусти Clawdmeter в трее.

## Обновление прошивки по Wi‑Fi

**Обновление лимитов** получает новые проценты через службу Windows. **OTA** переписывает программу на плате, например для замены набора анимаций. Для OTA экран должен бодрствовать, питание должно быть стабильным, а ПК и экран должны видеть друг друга в локальной сети.

1. Разбуди экран и проверь статус **«На связи»** в пульте.
2. Найди файл приложения, собранный для **`waveshare_amoled_216_c6`**. Собери его командой `pio run -d firmware -e waveshare_amoled_216_c6`. Для стандартной конфигурации результат находится в `firmware/.pio/build/waveshare_amoled_216_c6/firmware.bin`. Образы `*.factory.bin` предназначены для проводной установки и скрипт OTA их отклоняет.
3. Из папки проекта запусти команду для выбранного образа.

   ```powershell
   & '.\.venv\Scripts\python.exe' `
     '.\daemon\flash_wifi_windows.py' `
     '.\firmware\.pio\build\waveshare_amoled_216_c6\firmware.bin' `
     --espota (Join-Path $env:USERPROFILE ".platformio\packages\framework-arduinoespressif32\tools\espota.py")
   ```

4. Дождись `Success` и перезапуска. Затем проверь в пульте, что плата снова отвечает. Открой заставку левой кнопкой, чтобы увидеть результат обновления на экране.

Скрипт сначала находит плату через штатный обмен и использует подтверждённый адрес. Затем Arduino OTA аутентифицирует обновление. Если поиск платы проходит, но передача зависает на ожидании, проверь доступ по **UDP 3232** к устройству и обратное соединение к **TCP 32323** на ПК в домашней сети. При отсутствии ответа сначала разбуди экран и восстанови связь с пультом. Если Wi‑Fi так и не поднимается, вернись к USB-настройке. Восстановление с проводной перепрошивкой требуется, если текущая программа или загрузка платы повреждены.

Если PlatformIO использует другой каталог пакетов, подставь фактический путь к `espota.py`.

## Техническая справка для локальной интеграции

- **ПК → плата.** UDP **43621**. Модуль `WifiSync` отправляет UTF‑8 JSON, максимум **512 байт до шифрования**. Клиент использует AES-GCM и общий ключ настройки сети. Сначала пробует сохранённый IP, затем адреса широковещательной рассылки.
- **Плата → ПК.** Ответ привязан к запросу через HMAC-SHA256. Для заметок и лимитов приходит подтверждение доставки. Для запроса управления возвращается JSON со статусом. Запросы идут с ПК. Пульт узнаёт об изменении галочки при очередном опросе.
- **Лимиты.** В пакете поля `s` / `w` содержат использованные проценты, `sr` / `wr` — минуты до сброса, `ss` / `ws` — секунды, `sa` / `wa` — подписи с местным временем. Данные Codex передаются вложенным объектом `codex`. Обычное обновление формирует фоновая служба.
- **Команды.** `page=0/1/2` выбирает Claude, Codex или заметки, `brightness=0/1/2/3` — один из четырёх уровней, `interval` — секунды, `pin` — закрепление, `mode="splash"` или `mode="game"` — запуск режима.
- **Статус.** `checks` — битовая маска галочек в исходном порядке строк, `claudeAge` и `codexAge` — возраст данных в секундах, `-1` означает отсутствие первого обновления. `screenToday`, `screenWeek`, `screenTotal` и `chargeAge` передаются в секундах, `displayLit` показывает, горит ли дисплей. Для `chargeAge` значение `-2` означает внешнее питание, `-1` — отсутствие отсчёта.
- **Диагностика.** При подключении по USB последовательный порт работает на 115200 бод. Команда `wifi-status` показывает состояние сети и счётчики пакетов. Команда `screenshot` на этой C6-сборке отвечает `SCREENSHOT_UNSUPPORTED`. В текущей прошивке вывод звука на этой плате отключён.

Пример чтения статуса с ПК без изменения страницы, заметок или яркости. Из папки проекта открой PowerShell и выполни команду. Скрипт возьмёт ключ из уже настроенного локального файла.

```powershell
.\.venv\Scripts\python.exe -c 'from daemon.wifi_sync_windows import WifiSync; print(WifiSync().control())'
```

`None` означает, что плата не вернула подтверждённый ответ. Для собственного Python-скрипта чтение выполняется через `WifiSync().control()`, а отправка списка — через `WifiSync().send({"note": "Первое дело\nВторое дело"})`. Отправка заменяет весь список на плате. Для повседневного редактирования используй пульт, чтобы его копия текста совпадала со списком на экране.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Пульт пишет **«Экран не ответил по Wi‑Fi»** | Разбуди экран. Проверь, что ПК и плата в одной локальной сети. После смены пароля или роутера повтори настройку через USB. |
| Пульт **«На связи»**, а обе страницы ждут данные | Проверь значок фоновой службы в трее и интернет на ПК. Через один цикл посмотри возраст данных по обоим сервисам. |
| Работает только Claude или только Codex | Связь ПК с платой уже работает. Проверь вход и получение лимитов у второго сервиса. Для Claude ошибка `401` или `403` в журнале указывает на проблему авторизации. Для Codex проверь наличие `codex.exe` в окружении службы и вход в нужный аккаунт. |
| Числа стоят на месте | Сравни возраст данных. Если он возвращается к **«только что»**, плата получает новые пакеты. При росте возраста открой журнал службы. |
| Заметка не появилась | Дождись **«Список отправлен»**, открой страницу **«Заметки»** и проверь лимит длины. Во время глубокого сна сначала нужно разбудить плату. |
| Страницы перестали сменяться | Проверь закрепление и выжди 15 секунд после касания. Правая кнопка перелистывает сразу. |
| OTA не видит плату | Сначала проверь связь в пульте. Если пульт работает, проверь используемый файл и разрешения локального брандмауэра для OTA. |
| Время с последней зарядки пустое | При включённой плате подключи и отключи внешнее питание. Дождись обновления пульта. |

Последние строки журнала фоновой службы можно посмотреть из PowerShell.

```powershell
Get-Content "$env:LOCALAPPDATA\Clawdmeter\daemon.log" -Tail 40
```
